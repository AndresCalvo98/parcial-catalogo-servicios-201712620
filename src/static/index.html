Reglas de Tratamiento y Calidad de Datos Aplicadas

R1

Celdas Combinadas — Nivel 1 (Forward Fill)

Se aplicó ffill con Pandas para propagar el valor de la categoría padre a cada fila hija. Esto garantiza que cada servicio Nivel 2 conserve correctamente su agrupación Nivel 1 sin inventar registros artificiales.

R2

Conflicto de Código Duplicado — SE.12

Los nombres "Suministrar Analítica" y "Mantener Tableros de Control" compartían el código SE.12. Se consolidaron bajo el nombre canónico "Suministrar Analítica y Tableros de Control", preservando un único registro oficial.

R3

Atributos Incompletos — Filas 99 a 101

Se preservaron como valores nulos en base de datos. No se forzó ningún valor predeterminado arbitrario (cero, "N/A", etc.) para mantener la veracidad de los datos fuente.

R4

Normalización de Catálogos Auxiliares

Los valores de Clase, Criticidad y Tipo fueron extraídos y normalizados en tablas de catálogo separadas, eliminando redundancia y habilitando integridad referencial en la base de datos PostgreSQL.
