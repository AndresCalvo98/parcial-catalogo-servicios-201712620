# Sistema de Gestión del Catálogo de Servicios de TI

Aplicación web para sistematizar el catálogo de servicios de TI, incorporando usuarios y estructura organizacional. 

Este proyecto fue desarrollado como parte del parcial práctico del curso de **Software Avanzado**, aplicando técnicas de **Context Engineering, Prompt Engineering y Harness Engineering**.

## Requisitos Previos
- Docker y Docker Compose
- Node.js o Python (dependiendo del backend)
